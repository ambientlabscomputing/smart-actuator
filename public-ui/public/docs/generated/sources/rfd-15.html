# RFD-15: Public UI

## Purpose

The Public UI will be the landing page of the project. It serves these explicit goals:

1. **Attract new users to the project**
    - Users should hooked and curious about the project baesd on the content they see and interact with ont his ite
2. **Educate users on how to use the project**
    - Easy to access Get Started guides
3. **Host public docs for the project**
    - we'll wnat autogenerated API docs and the like
4. **Direct curious would-be custom development customers to the ambientlabs.io site**

## The Demo

This will be Crown Jewel of the public site and the biggest "oh shit, this is something special" for the visitor.

### The Vision

A WebAssmebly-fied smart actuator sim powers the demo. The user is presented with a skeumorphic representation of a stepper-like actuator motor. A simple but sleek interface allows the user to send data and read from the actuator
