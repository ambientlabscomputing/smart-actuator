pub fn wrap_to_pi(angle: f64) -> f64
Expand description

Wrap an angle (rad) into [-π, π).

Used by the position controller so the error always describes the shortest path around the circle. Without this, a setpoint just past the 0/2π seam (e.g. commanding 0 rad while the rotor sits at 2π⁻) yields an error of ~−2π and the motor drives the long way around instead of nudging forward across the seam.
