Expand description

Hardware I/O seam — the interface between control logic and physical (or simulated) drivers.

Real firmware implements this with HAL calls (encoder, ADC, PWM driver). The simulator implements it with SimPlant (dynamics model).

actuator-core depends ONLY on this trait — it never sees hardware or simulation details, which is what keeps the shared control code honest.
