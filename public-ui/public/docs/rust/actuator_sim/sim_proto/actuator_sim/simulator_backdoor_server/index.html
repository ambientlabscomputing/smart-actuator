SimulatorBackdoorServer
SimulatorBackdoor is served by actuator-sim ONLY. It lets external physics scenes (MuJoCo, test harnesses, etc.) poke ground-truth plant state, inject disturbances, and control sim time — completely separate from the controller’s view of the actuator.
